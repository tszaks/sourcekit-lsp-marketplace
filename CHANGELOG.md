# Changelog

All notable changes to this marketplace are listed here. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/). The repository has no tags. The plugin version is the one in `sourcekit-lsp/plugin.json`.

## [Unreleased]

### Added
- LICENSE (MIT), CONTRIBUTING, SECURITY, CODE_OF_CONDUCT, AGENTS.md, issue and pull request templates, and a CI workflow that checks the JSON files.

### Fixed
- README install step now points to `tszaks/sourcekit-lsp-marketplace` (it said `tjzaks`).

## [0.1.0] - 2025-12-25

### Added
- Initial plugin `sourcekit-lsp`: Swift and Objective-C language server support for Claude Code through Apple's SourceKit-LSP, for `.swift`, `.m`, `.mm` and `.h` files.
- README quickstart and a copyable summary for LLMs (2026-02-25).
